Development Log

Replication Manager

This document records the full development process of the replication-manager framework across two AI-assisted sessions: initial scaffolding with Codex, then feature development and testing with Claude Code.

Scope

April 18–20, 2026

Repository: github.com/ottoxin/replication-manager

Test paper: Hao et al. (2026), Nature 649, 1237–1243

Tools: Codex (Session 1), Claude Code (Session 2)

Goal

Build a pre-submission replication checker: ingest a paper and replication package, run code in a clean sandbox, compare outputs, and generate a report with side-by-side comparison.

Design

Compact agentic workflow inspired by Xu & Yang's AI-reproducibility paper. Three agents (Coordinator, Executor, Reporter + Analyst) with deterministic skills. No live LLM in the pipeline.

Final Result

Nature paper replication: 131/187 substantive claims matched (70%), 47 coincidental filtered, adjusted verdict "largely reproducible". 14 figures with HTML-downloaded images.

Key Design Decisions

  • Heuristic analysis over LLM API calls. The analysis.py module uses pattern-based classification instead of calling an LLM API. The Claude Code skill (/analyze-replication) provides deeper AI reasoning when invoked manually.
  • HTML figure download over PDF rendering. Individual figures from Nature/Springer CDN are higher quality than PDF page renders. DOI-based filtering prevents matching thumbnails from sidebar articles.
  • Adjusted verdicts. Raw match rates are inflated by coincidental matches (citations, versions, equation numbers). The adjusted rate counts only substantive research findings.
  • Screening reports visualization gaps. When a package has source data but no plotting scripts, the screening report explicitly flags this — the authors provided data but not the code to reproduce their figures.
  • No CSV preview in reports. Source data files are noted on the replicated side, but raw CSV content is not rendered. The information that matters is whether source data exists, not its contents.
